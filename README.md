# FreightFlow

Информационная система мониторинга и анализа логистической инфраструктуры Москвы:
реестр объектов, карта, дорожная сеть с ограничениями для грузового транспорта,
маршрутизация, оперативный мониторинг, аналитика, сценарии и отчёты на открытых данных.

## Требования для разработки

- Go 1.27
- Node.js 24
- Docker Desktop
- [Task](https://taskfile.dev) 3

## Запуск

```sh
cp .env.example .env    # заполнить ключи
task up                 # PostgreSQL + PostGIS, Mailpit
task serve              # веб-сервер на http://localhost:8080
```

Проверка перед коммитом: `task check`.

## Данные

Используются OpenStreetMap (© участники OpenStreetMap, ODbL), портал открытых данных
Правительства Москвы (CC BY 4.0) и официальная статистика. Источники и лицензии
указываются в интерфейсе, отчётах и выгрузках.
