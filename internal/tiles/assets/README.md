# Шрифты и значки подложки

Источник: [protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets),
коммит `028c18f713baecad011301ff7a69acc39bcc2ae7`.

- `fonts/` — глифы Noto Sans (Regular, Medium, Italic) в формате PBF для MapLibre: латиница,
  кириллица, знаки препинания, символы. Лицензия SIL Open Font License 1.1 (`fonts/LICENSE-OFL.txt`).
  Диапазоны вне этого набора сервер отдаёт пустыми.
- `sprites/` — значки подложки, светлая и тёмная темы, 1x и 2x. Получены из
  [tangrams/icons](https://github.com/tangrams/icons), лицензия MIT (`sprites/LICENSE.md`).
